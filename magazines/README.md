# Biweekly robotics & AI magazine updates

A selective reading digest for useful robotics and AI material at all levels. **At most four magazine articles per edition**, chosen for educational value, technical substance, importance, and freshness.

## Schedule

Every other Monday at **9:00 a.m. America/Chicago**, starting **2026-10-19**. The first edition was prepared on 2026-10-05. Folder names use `YYYY-MM-DD-magazine-update`; the edition heading keeps the readable month/day format.

Automatic runs use Windows Task Scheduler and the signed-in Codex CLI on this PC. The computer must be powered on, connected to the internet, and your Windows account signed in. Missed starts are allowed to run later. This is a local scheduled task, not a Codex app automation or GitHub-hosted workflow.

The task reads recent magazine articles, writes original notes, checks the article limit and duplicate links, and commits and pushes only magazine updates to this private repository. Existing editions are preserved. Logs stay on this PC.

## Selection rules

- Prefer original magazine articles published in the preceding 14 days; use the latest readable magazine issue only when necessary and clearly identify any older selection.
- Balance physical robotics and AI over time; prioritize reusable concepts and meaningful evidence.
- Prefer IEEE Spectrum, IEEE Robotics & Automation Magazine, and AAAI AI Magazine. Other established editorial magazines may be used when more relevant.
- Read actual articles, check publication dates, and exclude advertisements, sponsored pieces, video compilations, and duplicate URLs.
- Select fewer than four when there are fewer strong candidates. If none qualify, record that result rather than add filler.
- Each note includes the source link, date, summary, takeaways, highlighted learning priorities, and why it matters for your study.
